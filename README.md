A personal portfolio site built with React and Vite to showcase my frontend
work as a Software Engineering student and front-end developer.

## 📋 Overview

This project was built to present my projects in a way that feels closer to
my own design taste than a plain list — a soft, purple-and-pink visual
identity, a rotating-word hero introduction, and an interactive cursor trail
that previews project screenshots as you move around the page.

## ✨ Features

* Animated hero with a rotating word (Creative / Elegant / Dynamic /
  Intuitive / Seamless)
* Interactive cursor-trail section built with GSAP — moving the mouse (or a
  finger on touch devices) scatters small previews of each project
* Responsive project grid with hover motion and lazy-loaded images
* Smooth-scroll navigation between the hero and the projects section
* Fully responsive layout for desktop, tablet, and mobile

## 🛠️ Technologies Used

* React 19
* Vite
* JavaScript (ES6+)
* CSS3 (custom properties, keyframe animations)
* React Hooks — `useState`, `useEffect`, `useRef`
* GSAP (GreenSock Animation Platform)
* Google Fonts (Quicksand, Poppins) + Material Symbols icons

## 🚀 Getting Started

### Prerequisites

Make sure you have installed:

* Node.js
* npm

### Installation

Clone the repository:

```bash
git clone https://github.com/mymona-muhisen/<repo-name>.git
```

Navigate to the project directory, then install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:5173
```
